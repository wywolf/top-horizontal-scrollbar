# 横向进度条 Chrome 扩展

在网页顶部显示横向阅读进度条，并提供“顶部 / 最新”两个快捷滚动按钮，方便在长页面、文章页或带内部滚动容器的页面中快速定位阅读位置。

## 功能特性

- 顶部阅读进度条：根据当前滚动位置实时展示页面阅读进度。
- 快捷滚动按钮：滚动后显示“顶部”按钮，未到页面底部时显示“最新”按钮。
- 平滑滚动：点击按钮后平滑滚动到顶部或底部。
- 支持内部滚动容器：自动检测页面中的可滚动元素，适配部分单页应用和内容区域滚动页面。
- 动态页面适配：通过 `MutationObserver` 监听 DOM 变化，页面内容更新后会重新检测滚动区域。
- 按钮可拖动：两个按钮组成的按钮组可以拖动调整位置。
- 位置持久化：拖动后的位置会保存到 `chrome.storage.local`，刷新页面或打开其它网页后继续使用上次位置。
- 响应式样式：移动端会自动缩小按钮尺寸，并支持减少动画偏好设置。

## 文件说明

- `manifest.json`：Chrome 扩展配置，使用 Manifest V3，声明脚本、样式、图标和权限。
- `content.js`：核心逻辑，包括阅读进度计算、滚动按钮创建、可滚动容器检测、拖拽和位置保存。
- `progress.css`：进度条和滚动按钮样式。
- `assets/`：扩展图标资源。

## 安装与调试

这个扩展不需要构建步骤，可以直接作为未打包扩展加载。

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `packages/chrome-horizontal` 目录。
5. 打开或刷新一个普通网页，滚动页面查看顶部进度条和右下角按钮。

修改 `content.js`、`progress.css` 或 `manifest.json` 后，需要回到 `chrome://extensions/` 点击该扩展的刷新按钮，然后刷新目标网页。

## 使用说明

- 页面可滚动时，顶部会出现一条横向进度条。
- 向下滚动超过一定距离后，会显示“顶部”按钮。
- 距离底部还有一定距离时，会显示“最新”按钮。
- 点击“顶部”滚动到页面顶部，点击“最新”滚动到页面底部。
- 按住按钮组拖动即可调整位置，松手后自动保存。
- 如果只显示一个按钮时拖到窗口边缘，之后出现两个按钮，按钮组会自动重新限制在浏览器可视区域内。

## 权限说明

`manifest.json` 当前声明了以下权限：

- `storage`：保存滚动按钮拖动后的位置。
- `<all_urls>`：让内容脚本可以注入到所有网页，以便显示进度条和滚动按钮。

## 兼容性说明

- 使用 Manifest V3，适用于现代 Chrome 浏览器。
- 内容脚本会注入 `content.js` 和 `progress.css`。
- 扩展页面 CSP 配置为仅允许加载自身脚本，避免引入远程脚本。

## 开发备注

- 进度条元素 ID 为 `progress-bar`。
- 滚动按钮容器类名为 `scroll-buttons`。
- 单个滚动按钮类名为 `scroll-button`。
- 按钮位置存储键名为 `scrollButtonsPosition`。
- 普通页面调试时，如果没有 `chrome.storage.local`，会回退使用 `localStorage`。
